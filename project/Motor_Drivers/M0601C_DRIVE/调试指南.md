# M0601C 电机反馈通路调试指南

## 如何判断反馈通路是否正常

### 方法1：Keil调试器查看变量（推荐）

#### 步骤1：编译下载
1. Keil中编译项目（Build → Rebuild all target files）
2. 下载程序（Flash → Download）

#### 步骤2：进入调试模式
1. 点击 Debug → Start/Stop Debug Session (Ctrl+F5)
2. 程序暂停在main函数入口

#### 步骤3：添加观察变量
1. 打开Watch窗口：View → Watch Window → Watch 1
2. 在Watch窗口中添加以下变量：
   - `g_motorFeedback` （展开查看data数组）
   - `g_feedbackCount`

#### 步骤4：运行并观察
1. 点击Run (F5) 运行程序
2. 电机开始以330 RPM运行
3. 观察Watch窗口中的变量变化

### 正常状态判断

✅ **反馈通路正常**：
- `g_motorFeedback.isValid` = 1
- `g_feedbackCount` 每500ms增加1
- `g_motorFeedback.data[0]` = 1 (电机ID)
- `g_motorFeedback.data[1]` = 反馈帧类型
- PH10 LED不断闪烁

❌ **反馈通路异常**：
- `g_motorFeedback.isValid` = 0
- `g_feedbackCount` = 0 或不增加
- PH10 LED不闪烁

### 方法2：LED指示

- **PH10** - 每收到一次反馈闪烁一次
- **PH11** - 电机运行时常亮

## 反馈帧数据含义

根据数据手册，反馈帧格式为10字节：

| 字节 | 含义 |
|------|------|
| DATA[0] | 电机ID (1~4) |
| DATA[1] | 反馈帧类型 |
| DATA[2]~DATA[8] | 数据内容 |
| DATA[9] | CRC-8校验 |

## 常见问题排查

### 问题1：收不到反馈数据

**可能原因：**
1. 电机未上电
2. 串口接线错误（TX/RX接反）
3. 波特率不匹配
4. DMA配置错误

**排查步骤：**
1. 检查电机电源指示灯
2. 检查串口接线（PA9-TX, PB7-RX）
3. 确认波特率为115200
4. 在调试器中查看`s_rxBuf`变量

### 问题2：CRC校验失败

**现象：**
- `g_motorFeedback.isValid` = 0
- `g_feedbackCount` 不增加

**可能原因：**
1. 数据传输干扰
2. CRC算法错误

**排查步骤：**
1. 在调试器中查看`s_rxBuf`原始数据
2. 手动计算CRC验证

## 调试技巧

### 技巧1：单步调试接收回调

在 `HAL_UART_RxCpltCallback` 函数中设置断点：
1. 在该函数处设置断点
2. 运行程序，程序会停在断点处
3. 查看`s_rxBuf`数组内容
4. 单步执行验证CRC计算

### 技巧2：查看原始接收数据

在Watch窗口中添加：
- `s_rxBuf` - 查看原始接收缓冲区
- `s_feedback` - 查看反馈数据结构

### 技巧3：实时监控

使用Logic Analyzer窗口：
1. View → Analysis Windows → Logic Analyzer
2. 添加`g_feedbackCount`变量
3. 实时查看计数增长曲线
