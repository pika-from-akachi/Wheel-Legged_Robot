**一、功能Function**

1、2.4G遥控

2.4G remote control

2、与NRF24L01P模块通信

Communicate with NRF24L01P module

3、开机自动对码，避免多个遥控器同时使用造成干扰

Automatic code matching upon startup to avoid interference caused by multiple remote controls being used simultaneously

Dual joystick

5、6个实体按键

6 physical buttons

6、自动休眠

Automatic sleep mode

7、开放通信协议

Open Communication Protocol

8、提供UNO R3 Arduino、 51单片机、STM32通信协议实现例程

Provide UNO R3 Arduino, 51 microcontroller, STM32 communication protocol implementation routine

Install 2 No. 7 batteries

2、开机：电源开关拨到ON，指示灯亮起，蜂鸣器响一声

Power on: Turn the power switch to ON, the indicator light will light up, and the buzzer will sound once

3、遥控：操作摇杆或按键

Remote control: operating joystick or buttons

4、指示灯说明

Indicator light description

(1)闪烁：未连接设备

Blinking: Device not connected

(2)常亮：已连上设备

Continuously illuminated:Connected to device

(3)快闪：硬件错误

Fast flashing: Hardware error

5、自动休眠：未连接设备时，无操作约60秒后进行休眠，其中分别在40秒、50秒左右蜂鸣器会响两声进行提示

Automatic sleep mode: When the device is not connected and no operation is performed for about 60 seconds, it will enter sleep mode. The buzzer will sound twice at around 40 seconds and 50 seconds respectively to prompt

6、休眠唤醒：按下按键进行唤醒（摇杆无法唤醒）

Sleep wake-up: Press the button to wake up (joystick cannot wake up)

7、长时间不使用建议关闭电源

It is recommended to turn off the power if not used for a long time

四、通信协议 Communication protocol

1、对码流程 Code verification process

(1) 先启动设备，设备开机后默认地址必须为”HXFB0”

Start the device first, and the default address must be "HXFB0" after the device is turned on

(2)再启动遥控器，遥控器开机后默认连接地址为”HXFB0”的设备

Restart the remote control, and the default connection address for the device is "HXFB0" after the remote control is turned on

(3)设备接收到遥控器数据后，返回应答数据，应答数据包含对码地址

After receiving remote control data, the device returns response data, which includes the code address

(4) 遥控器接收到对码地址之后，将使用该地址作为通信地址，向设备发送数据

After receiving the code address, the remote control will use it as the communication address to send data to the device
