# EL05电机驱动 - 快速入门

## 🎯 5分钟快速上手

### 步骤1：添加文件到工程

将以下文件添加到你的Keil工程：

**头文件（.h）：**
- `Core/Inc/el05_motor.h`
- `Core/Inc/can_rx_handler.h`

**源文件（.c）：**
- `Core/Src/el05_motor.c`
- `Core/Src/can_rx_handler.c`

---

### 步骤2：修改main.c

```c
/* Includes ------------------------------------------------------------------*/
#include "main.h"
#include "can.h"
#include "el05_motor.h"

/* Private variables ---------------------------------------------------------*/
EL05_MotorHandle_t motor1;  // 电机句柄

int main(void)
{
    /* MCU初始化 */
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_CAN1_Init();

    /* 初始化EL05电机驱动 */
    EL05_Init(&hcan1);
    EL05_StartReception();

    /* 配置电机 */
    motor1.can_id = 0x01;  // 电机CAN ID
    EL05_Enable(&motor1);  // 使能电机
    HAL_Delay(100);

    /* 主循环 */
    while (1)
    {
        // 在这里添加控制代码
        // 示例：位置控制
        EL05_PositionControl(&motor1, 3.14f, 5.0f);  // 转到180度
        HAL_Delay(100);
    }
}
```

## 📝 常用控制示例

### 示例1：位置控制（转到指定角度）

```c
// 转到0度
EL05_PositionControl(&motor1, 0.0f, 5.0f);
HAL_Delay(1000);

// 转到180度 (π rad)
EL05_PositionControl(&motor1, 3.14f, 5.0f);
HAL_Delay(1000);

// 转到-180度 (-π rad)
EL05_PositionControl(&motor1, -3.14f, 5.0f);
HAL_Delay(1000);
```

---

### 示例2：速度控制（恒速转动）

```c
// 以2 rad/s的速度转动
EL05_VelocityControl(&motor1, 2.0f, 5.0f);
HAL_Delay(5000);  // 转动5秒

// 停止
EL05_VelocityControl(&motor1, 0.0f, 5.0f);
```

---

### 示例3：MIT模式（力控）

```c
EL05_MitControl_t cmd;

// 设置目标位置和刚度
cmd.p_des = 0.0f;   // 目标位置
cmd.v_des = 0.0f;   // 目标速度
cmd.kp = 20.0f;     // 位置刚度（越大越硬）
cmd.kd = 1.0f;      // 阻尼
cmd.t_ff = 0.0f;    // 前馈力矩

EL05_MitControl(&motor1, &cmd);
```

---

### 示例4：读取电机状态

```c
// 检查电机是否在线
if (EL05_CheckOnline(&motor1, 100))
{
    // 获取反馈数据
    EL05_MotorFeedback_t *fb = EL05_GetFeedback(&motor1);

    // 使用数据
    float pos = fb->position;    // 位置 (rad)
    float vel = fb->velocity;    // 速度 (rad/s)
    float torque = fb->torque;   // 力矩 (N·m)
    float temp = fb->temperature; // 温度 (℃)
}
```

---

### 示例5：正弦运动

```c
float time = 0.0f;

while (1)
{
    // 生成正弦轨迹
    float pos = 3.0f * sinf(2.0f * 3.14159f * 0.5f * time);

    // 控制电机跟随轨迹
    EL05_PositionControl(&motor1, pos, 10.0f);

    time += 0.01f;
    HAL_Delay(10);  // 100Hz控制频率
}
```

## ⚡ 单位说明

| 参数   | 单位    | 说明                    |
|--------|---------|------------------------|
| 位置   | rad     | 弧度 (π rad = 180°)    |
| 速度   | rad/s   | 弧度每秒               |
| 力矩   | N·m     | 牛顿·米                |
| 电流   | A       | 安培                   |
| 温度   | ℃       | 摄氏度                 |

**角度转换：**
- 180° = π rad ≈ 3.14 rad
- 90° = π/2 rad ≈ 1.57 rad
- 360° = 2π rad ≈ 6.28 rad

## 🔧 调试技巧

### 1. 电机不动？

**检查清单：**
- [ ] 电源是否连接（48V）
- [ ] CAN线是否连接正确（H-H, L-L）
- [ ] 电机是否使能（`EL05_Enable()`）
- [ ] CAN ID是否正确（默认0x01）
- [ ] 终端电阻是否添加（120Ω）

### 2. 电机抖动？

**解决方法：**
- 降低控制增益（Kp, Kd）
- 减小控制频率
- 检查机械负载

### 3. CAN通信失败？

**检查项：**
- CAN波特率是否为1Mbps
- CAN_H和CAN_L是否接反
- 终端电阻是否正确
