# EL05电机驱动使用指南

## 📖 概述

本文档介绍如何使用EL05电机驱动程序驱动准直驱6N·m一体化电机模组。

**电机规格：**
- 额定电压：48V DC
- 额定扭矩：1.8 N·m
- 峰值扭矩：6 N·m
- 空载转速：430 rpm
- 减速比：9:1
- 通信接口：CAN 2.0扩展帧，1Mbps

---

## 🚀 快速开始

### 1. 硬件连接

**电源连接：**
- VBAT+ → 48V电源正极（15V-60V）
- GND → 电源负极

**CAN连接：**
- CAN_H → CAN总线高
- CAN_L → CAN总线低
- **注意：** CAN总线两端需要120Ω终端电阻

**开发板连接：**
- PD0 → CAN1_RX
- PD1 → CAN1_TX

### 2. 软件配置

**步骤1：** CubeMX已配置好CAN1（1Mbps波特率）

**步骤2：** 将以下文件添加到工程：
- `Core/Inc/el05_motor.h`
- `Core/Src/el05_motor.c`

**步骤3：** 在main.c中包含头文件：
```c
#include "el05_motor.h"
```

**步骤4：** 初始化电机驱动：
```c
// 在main函数中
EL05_Init(&hcan1);  // 初始化驱动
EL05_StartReception();  // 启动CAN接收
```

## 📚 API函数说明

### 1. 基础控制函数

#### 1.1 使能电机
```c
EL05_MotorHandle_t motor;
motor.can_id = 0x01;  // 电机CAN ID

EL05_Enable(&motor);  // 使能电机
```

#### 1.2 停止电机
```c
EL05_Disable(&motor);  // 停止电机
```

#### 1.3 设置控制模式
```c
// 设置为MIT模式
EL05_SetMode(&motor, EL05_MODE_MIT);

// 设置为位置模式CSP
EL05_SetMode(&motor, EL05_MODE_CSP);

// 设置为速度模式
EL05_SetMode(&motor, EL05_MODE_VELOCITY);

// 设置为电流模式
EL05_SetMode(&motor, EL05_MODE_CURRENT);
```

---

### 2. MIT模式控制（运控模式）

MIT模式是最灵活的控制方式，可以同时控制位置、速度和力矩。

```c
EL05_MitControl_t mit_cmd;

mit_cmd.p_des = 0.0f;   // 目标位置 (rad), 范围: -12.5 ~ 12.5
mit_cmd.v_des = 1.0f;   // 目标速度 (rad/s), 范围: -30 ~ 30
mit_cmd.kp = 10.0f;     // 位置增益, 范围: 0 ~ 500
mit_cmd.kd = 0.5f;      // 速度增益, 范围: 0 ~ 5
mit_cmd.t_ff = 0.0f;    // 前馈力矩 (N·m), 范围: -18 ~ 18

EL05_MitControl(&motor, &mit_cmd);
```

**控制原理：**
```
输出力矩 = Kp × (p_des - p_actual) + Kd × (v_des - v_actual) + t_ff
```

**应用场景：**
- 机器人关节控制
- 力控应用
- 阻抗控制

---

### 3. 位置控制（CSP模式）

精确的位置控制模式。

```c
float target_position = 3.14f;  // 目标位置 (rad)
float velocity_limit = 5.0f;    // 速度限制 (rad/s)

EL05_PositionControl(&motor, target_position, velocity_limit);
```

**应用场景：**
- 点位控制
- 轨迹跟踪
- 精确定位

---

### 4. 速度控制

恒定速度控制模式。

```c
float target_velocity = 2.0f;   // 目标速度 (rad/s)
float current_limit = 5.0f;     // 电流限制 (A)

EL05_VelocityControl(&motor, target_velocity, current_limit);
```

**应用场景：**
- 轮子控制
- 风扇控制
- 恒速应用

---

### 5. 电流控制

直接控制电机电流（力矩）。

```c
float target_current = 1.0f;  // 目标电流 (A)

EL05_CurrentControl(&motor, target_current);
```

**应用场景：**
- 力控应用
- 电流测试
- 底层调试

---

### 6. 辅助函数

#### 6.1 设置机械零位
```c
EL05_SetZeroPosition(&motor);  // 将当前位置设为零位
```

#### 6.2 读取反馈数据
```c
EL05_MotorFeedback_t *feedback = EL05_GetFeedback(&motor);

float position = feedback->position;     // 位置 (rad)
float velocity = feedback->velocity;     // 速度 (rad/s)
float torque = feedback->torque;         // 力矩 (N·m)
float temperature = feedback->temperature; // 温度 (℃)
```

#### 6.3 检查在线状态
```c
if (EL05_CheckOnline(&motor, 100)) {
    // 电机在线
} else {
    // 电机离线
}
```

#### 6.4 读写参数
```c
// 写参数（掉电丢失）
EL05_WriteParam(&motor, 0x7005, 2.0f);  // 写入参数

// 读参数
EL05_ReadParam(&motor, 0x7005);  // 读取参数
```

## 💡 使用示例

### 示例1：简单的位置控制

```c
// 初始化
EL05_Init(&hcan1);
EL05_StartReception();

motor.can_id = 0x01;
EL05_Enable(&motor);
HAL_Delay(100);

// 控制循环
while (1) {
    // 转到位置π (180°)
    EL05_PositionControl(&motor, 3.14f, 5.0f);
    HAL_Delay(100);

    // 转到位置-π (-180°)
    EL05_PositionControl(&motor, -3.14f, 5.0f);
    HAL_Delay(100);
}
```

### 示例2：正弦运动

```c
float time = 0.0f;
float amplitude = 3.0f;  // 振幅 (rad)
float frequency = 0.5f;  // 频率 (Hz)

while (1) {
    float position = amplitude * sinf(2.0f * 3.14159f * frequency * time);
    EL05_PositionControl(&motor, position, 10.0f);

    time += 0.01f;
    HAL_Delay(10);  // 100Hz控制频率
}
```

### 示例3：MIT模式力控

```c
EL05_MitControl_t cmd;
cmd.p_des = 0.0f;   // 目标位置
cmd.v_des = 0.0f;   // 目标速度
cmd.kp = 20.0f;     // 位置刚度
cmd.kd = 1.0f;      // 阻尼
cmd.t_ff = 0.5f;    // 前馈力矩

EL05_MitControl(&motor, &cmd);
```

## ⚠️ 注意事项

### 1. 安全事项

**⚠️ 电源电压**
- 工作电压范围：15V - 60V
- 额定电压：48V
- **严禁超过60V！**

**⚠️ 扭矩限制**
- 额定扭矩：1.8 N·m
- 峰值扭矩：6 N·m（持续时间见下表）

| 扭矩 (N·m) | 持续时间 (s) |
|-----------|-------------|
| 6         | 5           |
| 5         | 7           |
| 4         | 14          |
| 3         | 44          |
| 2         | 300         |
| 1.8       | 连续        |

**⚠️ 温度保护**
- 工作温度：-20℃ ~ 50℃
- 保护温度：145℃（自动停机）

### 2. 通信注意事项

**⚠️ CAN波特率**
- 必须设置为1Mbps
- 与电机波特率一致

**⚠️ CAN ID**
- 默认CAN ID：0x01
- 可通过上位机修改
- 同一CAN总线上不能有重复ID

**⚠️ 控制频率**
- MIT模式：建议100Hz（10ms周期）
- 位置模式：建议10-100Hz
- 速度模式：建议10-100Hz

**⚠️ 模式切换**
- 切换控制模式前必须先停止电机
- 切换后需要重新使能

### 3. 常见问题

**Q1: 电机不转动？**
- 检查电源电压是否正常
- 检查CAN连接是否正确
- 检查电机是否使能
- 检查CAN ID是否正确

**Q2: 电机抖动？**
- 降低控制增益（Kp, Kd）
- 检查机械负载是否过大
- 检查电源电压是否稳定

**Q3: 电机过热？**
- 降低负载
- 降低峰值扭矩使用时间
- 检查环境温度

**Q4: CAN通信失败？**
- 检查CAN_H和CAN_L是否接反
- 检查终端电阻（120Ω）
- 检查波特率设置
