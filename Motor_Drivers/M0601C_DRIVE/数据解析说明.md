# M0601C 电机数据解析说明

## 反馈帧格式

根据Excel换算公式，反馈帧数据格式如下：

| 字节 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| DATA[0] | 电机ID | uint8_t | 电机ID (1~4) |
| DATA[1] | 帧类型/模式 | uint8_t | 反馈帧类型标识 |
| DATA[2] | 电流高字节 | int16_t高8位 | 电流数据高字节 |
| DATA[3] | 电流低字节 | int16_t低8位 | 电流数据低字节 |
| DATA[4] | 速度高字节 | int16_t高8位 | 速度数据高字节 |
| DATA[5] | 速度低字节 | int16_t低8位 | 速度数据低字节 |
| DATA[6] | 位置高字节 | uint16_t高8位 | 位置数据高字节 |
| DATA[7] | 位置低字节 | uint16_t低8位 | 位置数据低字节 |
| DATA[8] | 温度/状态 | uint8_t | 电机温度或状态字 |
| DATA[9] | CRC | uint8_t | CRC-8/MAXIM校验 |

## 换算公式

### 1. 电流换算

**公式：** `电流(mA) = 8000 × signed(DATA[2:3]) / 32767`

**示例：**
- DATA[2:3] = 0xFFD0 (-48)
- 电流 = 8000 × (-48) / 32767 = -11.7 mA

**代码实现：**
```c
int16_t currentRaw = (int16_t)((data[2] << 8) | data[3]);
pStatus->current = (int16_t)((8000L * currentRaw) / 32767);
```

### 2. 速度换算

**公式：** `速度(rpm) = signed(DATA[4:5])`

**示例：**
- DATA[4:5] = 0x014E (334)
- 速度 = 334 rpm

**代码实现：**
```c
pStatus->speed = (int16_t)((data[4] << 8) | data[5]);
```

### 3. 位置换算（十进制）

**公式：** `位置 = unsigned(DATA[6:7])`

**示例：**
- DATA[6:7] = 0x1179 (4473)
- 位置 = 4473

**代码实现：**
```c
pStatus->position = (int16_t)((data[6] << 8) | data[7]);
```

### 4. 位置换算（角度，可选）

**公式：** `角度(°) = unsigned(DATA[6:7]) × 360 / 32768`

**示例：**
- DATA[6:7] = 0x2000 (8192)
- 角度 = 8192 × 360 / 32768 = 90°

**如需使用：**
```c
float angle = (float)((data[6] << 8) | data[7]) * 360.0f / 32768.0f;
```

## 数据范围

| 参数 | 最小值 | 最大值 | 单位 |
|------|--------|--------|------|
| 电流 | -8000 | +8000 | mA |
| 速度 | -32768 | +32767 | rpm |
| 位置 | 0 | 65535 | - |
| 位置（角度）| 0 | 360 | ° |

## 有符号16位数据处理

对于有符号16位数据（电流、速度），处理方法：

```c
int16_t signedValue = (int16_t)((highByte << 8) | lowByte);
```

这会自动处理：
- 正数：0x0000 ~ 0x7FFF → 0 ~ 32767
- 负数：0x8000 ~ 0xFFFF → -32768 ~ -1

## 调试器中查看解析结果

在Keil调试器的Watch窗口中添加：

```
g_motorStatus
```

展开后可以查看：
- `motorId` - 电机ID
- `current` - **电流 (mA)**，已换算
- `speed` - **速度 (rpm)**，已换算
- `position` - **位置**，已换算
- `temperature` - 温度 (°C)
- `mode` - 当前模式
- `isValid` - 数据有效性

## 验证方法

### 步骤1：查看原始数据

在Watch窗口中添加：
```
g_motorFeedback.data[10]
```

### 步骤2：手动计算验证

假设收到：
```
data[10] = {0x01, 0x74, 0xFF, 0xD0, 0x01, 0x4E, 0x11, 0x79, 0x2D, 0xXX}
```

手动计算：
- 电流原始值 = 0xFFD0 = -48 (有符号)
- 电流(mA) = 8000 × (-48) / 32767 = -11.7 mA
- 速度 = 0x014E = 334 rpm
- 位置 = 0x1179 = 4473

### 步骤3：对比解析结果

查看 `g_motorStatus` 中的值是否与手动计算一致。

## 注意事项

1. **DATA字节顺序**：DATA[2:3]表示电流，DATA[4:5]表示速度（不是DATA[2:3]是速度）
2. **有符号处理**：电流和速度都是有符号16位，注意正确处理负数
3. **精度损失**：电流计算时除以32767会有舍入误差，这是正常的
4. **温度字段**：DATA[8]的具体含义需要确认是温度还是状态字

## 已知问题

- DATA[1] 模式字段的具体含义需要实际验证
- DATA[8] 温度字段可能需要额外的换算公式
- 位置数据可以转换为角度，当前代码未实现角度换算
