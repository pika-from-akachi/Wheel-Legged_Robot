# M0601C 电机状态实时监控指南

## 功能说明

系统已实现电机反馈数据的自动解析，将原始10字节数据转换为具体的物理量，可在调试器中实时查看。

## 在Keil调试器中查看解析后的数据

### 步骤1：编译下载程序
1. Keil中编译项目
2. 下载程序到开发板

### 步骤2：进入调试模式
1. Debug → Start/Stop Debug Session (Ctrl+F5)

### 步骤3：添加变量到Watch窗口
1. View → Watch Window → Watch 1
2. 添加以下变量：

**解析后的电机状态（推荐）：**
```
g_motorStatus
```

展开后可以看到：
- `motorId` - 电机ID (1~4)
- `speed` - **当前转速 (RPM)**，有符号，正数=正转，负数=反转
- `current` - **当前电流 (mA)**，有符号
- `position` - **当前位置**
- `temperature` - **电机温度 (°C)**
- `mode` - 当前控制模式 (01=电流环，02=速度环，03=位置环)
- `faultCode` - 故障码
- `isValid` - 数据有效性标志

**原始反馈数据：**
```
g_motorFeedback
```

**调试信息：**
```
g_debug
```

### 步骤4：运行程序观察
1. 点击 Run (F5)
2. 电机开始以330 RPM运行
3. 观察Watch窗口中的变量实时更新

## 反馈帧格式说明

### 当前实现的解析格式

```
字节   | 含义             | 数据类型
-------|------------------|------------------
DATA[0]| 电机ID           | uint8_t
DATA[1]| 帧类型/模式      | uint8_t
DATA[2]| 速度高字节       | int16_t高8位
DATA[3]| 速度低字节       | int16_t低8位
DATA[4]| 电流高字节       | int16_t高8位
DATA[5]| 电流低字节       | int16_t低8位
DATA[6]| 位置高字节       | int16_t高8位
DATA[7]| 位置低字节       | int16_t低8位
DATA[8]| 温度/状态        | uint8_t
DATA[9]| CRC校验         | uint8_t
```

### ⚠️ 重要提示

**上述格式是推测的常见格式，可能需要根据实际数据手册调整！**

如果实际接收到的数据与解析结果不符，请：

1. 在调试器中查看 `g_motorFeedback.data[10]` 原始数据
2. 对比数据手册中的反馈帧格式
3. 修改 `MOTOR_ParseFeedback()` 函数中的解析逻辑

## 如何调整解析格式

如果实际数据格式不同，请修改文件：
`Core/Src/motor_driver.c` 中的 `MOTOR_ParseFeedback()` 函数

例如，如果速度实际在DATA[3:4]而非DATA[2:3]：

```c
/* 修改前 */
pStatus->speed = (int16_t)((data[2] << 8) | data[3]);

/* 修改后 */
pStatus->speed = (int16_t)((data[3] << 8) | data[4]);
```

## 实时监控示例

### 正常运行状态

```
g_motorStatus = {
    motorId: 1,
    speed: 330,      // 正转330 RPM
    current: 500,    // 电流500mA
    position: 1234,  // 位置值
    temperature: 45, // 温度45°C
    mode: 2,         // 速度环模式
    faultCode: 0,    // 无故障
    isValid: 1       // 数据有效
}
```

### 反转状态

```
g_motorStatus.speed = -330  // 反转330 RPM
```

### 故障状态

```
g_motorStatus.faultCode = 1  // 有故障
g_motorStatus.isValid = 1     // 数据仍有效
```

## 调试技巧

### 技巧1：对比原始数据和解析结果

在Watch窗口中同时添加：
- `g_motorFeedback.data[10]` - 原始数据
- `g_motorStatus.speed` - 解析后的速度

手动验证解析是否正确。

### 技巧2：实时监控关键参数

只关注最重要的参数：
- `g_motorStatus.speed` - 速度
- `g_motorStatus.current` - 电流
- `g_motorStatus.temperature` - 温度

### 技巧3：使用Logic Analyzer

1. View → Analysis Windows → Logic Analyzer
2. 添加 `g_motorStatus.speed`
3. 实时查看速度变化曲线

## 故障排查

### 问题1：g_motorStatus.isValid = 0

**原因：** 未收到有效反馈数据

**解决：**
1. 检查 `g_motorFeedback.isValid`
2. 检查硬件连接

### 问题2：解析结果不正确

**原因：** 反馈帧格式不匹配

**解决：**
1. 查看 `g_motorFeedback.data[10]` 原始数据
2. 对比数据手册调整 `MOTOR_ParseFeedback()` 函数

### 问题3：数据不更新

**原因：** 回调函数未触发

**解决：**
1. 查看 `g_debug.rxCpltCallback` 是否增加
2. 检查 `g_debug.crcError` 是否有CRC错误
